# How to grade

Open your own file. Everyone has a different one and they do not overlap
completely, so please only work in the file with your name on it.

## Codes

Each row is one answer. Each column is one component of that task.
Put one code in every component cell:

| Code | Meaning |
|------|---------|
| **1** | The answer states the component |
| **0** | The answer does not mention it |
| **X** | The answer says something wrong about it, on the same point |

## Rules

- **Work alone.** Please do not compare notes while grading. We are checking
  whether the rubric works on its own, so agreement reached by talking does not
  tell us what we need to know.
- **No totals.** The component codes are the only thing we need.
- **If the rubric does not cover a case**, leave the cell blank and write why in
  `adjudication_note`. Anyi handles those. Please do not decide them yourself.

## What you can see

Task ID and answer text only. No participant IDs, no idiom labels. That is
deliberate, so please do not try to look them up.

The **Rubric** sheet inside your own file has every component statement, its
anchors and its notes. You should not need any other file.

## Two to expect trouble on

**10d** and **11c** do not have a positive anchor yet, because no answer in the
calibration sample stated them clearly. They may feel vague. Grade them as best
you can. If we end up disagreeing a lot on them we will rewrite those two and
re-grade just those.
